# Project Knight

Download **[ProjectKnight-win-Setup.exe](https://github.com/Kermitis/ProjectKnight/releases/latest/download/ProjectKnight-win-Setup.exe)** and run it. The launcher installs itself and keeps itself up to date.

On first start it downloads the game server files (about 180 MB). Fortnite builds are not included: choose the folder that holds your own builds in Options.

Windows Defender may flag `Erbium.dll` (the game server DLL). This is a false positive common to DLLs that load into a game.
